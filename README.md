# Цифровой деканат будущего (концепт)

Рабочий прототип личного кабинета студента для конкурса **MGIMO AI Challenge**, номинация «Вайб-кодинг».
**Не официальный сервис вуза. Все данные вымышленные.**

**Прототип:** https://ivanalsuhov-star.github.io/digital-dekanat/

## Что внутри
- Вход по почте и паролю, профиль студента (ФИО, факультет, направление, курс, группа)
- Расписание на сегодня и на неделю: аудитория, преподаватель, переносы, отмены и замены выделены цветом
- Успеваемость: баллы текущего контроля и «сколько не хватает до допуска», даты сессии, зачётка, средний балл
- Заявки и справки: заказ справки или заявление, которое собирается из данных профиля; статус по шагам и код выдачи
- Уведомления: объявления деканата, дедлайны, изменения расписания, статусы заявок
- Связь с деканатом: обращения-чаты с подсказками из FAQ ещё до отправки
- Кабинет сотрудника деканата: обработка заявок, ответы на обращения, публикация объявлений

## Как устроено
Один файл `index.html`: HTML, CSS, JavaScript без сборки, шрифт Manrope (Google Fonts, OFL).
Данные лежат в хранилище браузера. Доступ к ним идёт только через слой `API`, который проверяет сессию и роль.
Пароли хранятся как хеш PBKDF2-SHA256 (100 000 итераций, соль). В коде нет ни паролей, ни ключей.
Подробнее о процессе разработки с ИИ: [PROCESS.md](PROCESS.md).
